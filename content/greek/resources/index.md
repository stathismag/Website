## Οι συμβουλές μου {#curated-tips}

**Παρακολούθηση της βιβλιογραφίας.** Εγγραφείτε σε ειδοποιήσεις του [NBER](https://www.nber.org/papers/) και του [SSRN](https://www.ssrn.com/) για εταιρική χρηματοοικονομική και λογιστική. Για χρηματοοικονομική, αξίζει το newsletter [*Insights for Young Researchers in Finance*](https://insight4finance.substack.com/). Παρακολουθώ επίσης ειδοποιήσεις [RePEc](https://ideas.repec.org/) για νέα working papers.

**Ροή εργασίας.** Οργανώστε κάθε εμπειρικό έργο ώστε να μπορείτε να επιστρέψετε σε αυτό μετά από μήνες: ξεχωριστοί φάκελοι για raw data, cleaned data, do-files και output· README με πηγές δεδομένων· κώδικας υπό version control στο GitHub. [Ο οδηγός Stata workflow του Asjad Naqvi](https://asjadnaqvi.github.io/stata/) εφαρμόζεται καλά σε εργασίες εταιρικής χρηματοοικονομικής.

**Μιλήστε με νεότερους καθηγητές.** Ρωτήστε όχι μόνο για θέματα έρευνας, αλλά και για πρακτικά ζητήματα — οργάνωση έργων, χειρισμός κριτών, επιλογή περιοδικών, διαχείριση χρόνου.
