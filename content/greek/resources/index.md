## Οι συμβουλές μου {#curated-tips}

**Παρακολούθηση της βιβλιογραφίας.** Εγγραφείτε σε ειδοποιήσεις του [NBER](https://www.nber.org/papers/) και του [SSRN](https://www.ssrn.com/) για εταιρική χρηματοοικονομική και λογιστική. Για χρηματοοικονομική, δείτε το [Insights for Young Researchers in Finance](https://www.iwh-halle.de/ueber-das-iwh/forschungsabteilungen/insights-for-young-researchers-in-finance/). Παρακολουθώ επίσης ειδοποιήσεις [RePEc](https://ideas.repec.org/) για νέα working papers.

**Ροή εργασίας.** Οργανώστε κάθε εμπειρικό έργο ώστε να μπορείτε να επιστρέψετε σε αυτό μετά από μήνες: ξεχωριστοί φάκελοι για raw data, cleaned data, do-files και output· README με πηγές δεδομένων· κώδικας υπό version control στο GitHub. [Ο οδηγός Stata workflow του Asjad Naqvi](https://asjadnaqvi.github.io/stata/) εφαρμόζεται καλά σε εργασίες εταιρικής χρηματοοικονομικής.
